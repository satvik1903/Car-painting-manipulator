# Robotic Car Painting Cell Simulation

**Name:** Satvik Tajane
**Software used:** ROS 2 Jazzy, Gazebo Harmonic, MoveIt 2
**Robot selected:** KUKA KR 20 R3100 (KR IONTEC), inverted on an overhead XY gantry

Work in progress. Simulation of a single industrial robot painting the exterior of a car body (4800 x 1900 x 1600 mm).
